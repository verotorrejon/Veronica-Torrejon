# Fotografías opcionales

La versión entregada funciona completa sin fotografías ni imágenes externas.

Cuando Verónica seleccione fotografías personales, se recomienda incorporar entre 5 y 7 imágenes auténticas:

- Un retrato principal natural, con fondo limpio y formato vertical.
- Una fotografía presentando o participando en una reunión de trabajo.
- Una imagen vinculada a un proyecto o implementación.
- Una fotografía de voluntariado o actividad comunitaria cuya publicación esté autorizada.
- Una imagen de experiencia internacional.
- Una fotografía de running o de un interés personal.

Antes de publicarlas, se debe contar con autorización de las personas identificables y evitar imágenes que expongan información interna de empresas, pantallas, credenciales o datos de clientes.

Formatos recomendados: WebP o AVIF, máximo 1.600 px en su lado mayor y, de ser posible, menos de 300 KB por archivo.
