# Vero Torrejon — Portfolio

Portfolio personal tipo LinkedIn + portafolio.

## Archivos
- index.html
- style.css
- script.js
- images/ para fotografías

## Publicar en GitHub Pages
1. Crea un repositorio nuevo, por ejemplo `vero-portfolio`.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `images`.
3. Ve a Settings → Pages.
4. En Source selecciona Deploy from a branch.
5. Selecciona `main` y `/ (root)`.
6. Guarda. GitHub publicará el sitio.

## Fotos
Los bloques actuales son placeholders y dicen qué tipo de foto conviene poner.
Cuando tengas una foto, súbela a `images/` y reemplaza el placeholder por una etiqueta `<img>`.

## Antes de publicar
- Cambiar `TU_EMAIL_AQUI`.
- Reemplazar el enlace genérico de LinkedIn por tu perfil.
- Revisar cargos, fechas y cifras.
- Mantener solo información profesional que quieras hacer pública.
