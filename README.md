# Portafolio profesional de Verónica Torrejón

Sitio estático y responsivo preparado para GitHub Pages. Presenta la trayectoria profesional, proyectos, formación, impacto social e intereses de Verónica desde una perspectiva integral y verificable.

## Archivos para publicar

```text
index.html
style.css
script.js
assets/
  favicon.svg
images/
  README.md
```

## Actualizar el sitio existente en GitHub

1. Ingresa al repositorio `Veronica-Torrejon`.
2. Conserva una copia de la versión actual por seguridad.
3. Reemplaza en la raíz los archivos `index.html`, `style.css` y `script.js`.
4. Sube las carpetas `assets` e `images` manteniendo exactamente sus nombres.
5. Confirma los cambios en la rama que publica GitHub Pages, normalmente `main`.
6. Espera uno o dos minutos y abre:
   `https://verotorrejon.github.io/Veronica-Torrejon/`
7. Si todavía aparece la versión anterior, actualiza sin caché con `Ctrl + F5` en Windows o `Cmd + Shift + R` en Mac.

No requiere instalación, compilación, dependencias ni servidor especial.

## Contenido y veracidad

El sitio utiliza solamente antecedentes compartidos y confirmados para el CV de Verónica. No se incorporaron porcentajes, presupuestos, tamaños de equipo ni resultados que no estuvieran respaldados.

Cuando se confirmen nuevas métricas, conviene actualizar especialmente:

- Crecimiento de ventas y cumplimiento de metas de KIOSKO.
- Número de tiendas y equipos incluidos en la renovación.
- Reducción de incidencias y tiempos de atención.
- Personas capacitadas y medios de pago habilitados.
- Cantidad de casos de negocio y proyectos priorizados.

## Prueba local

Se puede abrir `index.html` directamente en el navegador. Para una prueba más fiel, también puede iniciarse un servidor local desde esta carpeta:

```bash
python -m http.server 8000
```

Luego se abre `http://localhost:8000`.
